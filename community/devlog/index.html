Rich Text Editor References

Use the toolbar above the editor to format your text. Here are some common options:

  • Bold: Select text and click the 'B' icon.
  • Italic: Select text and click the 'I' icon.
  • Underline: Select text and click the 'U' icon.
  • Strikethrough: Select text and click the 'S' icon.

  • Heading 1:

    Select text and choose 'Heading 1' from the dropdown.

  • Heading 2:

    Select text and choose 'Heading 2' from the dropdown.
  • Bulleted List: Click the bullet list icon.
  • Numbered List: Click the numbered list icon.
  • Blockquote: Click the blockquote icon.
  • Code Block: Click the code block icon.
  • Link: Select text, click the link icon, and enter the URL.
  • Image: Click the image icon and provide an image URL.

Experiment with the toolbar buttons to discover all formatting options!
